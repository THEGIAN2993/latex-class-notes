Let $(X,\cM,\mu)$ be a measure space. Let $f,g \in L^1(X)$. I'm trying to show that the set:
    \begin{equation*}
    \begin{split}
        \{x \mid |f(x)| \leq g(x)\}
    \end{split}
    \end{equation*}
is a measurable set. The above set can be written as:
    \begin{equation*}
    \begin{split}
        \{x \mid 0 \leq f(x) + g(x)\} \cap \{x \mid 0 \leq g(x) - f(x)\}
    \end{split}
    \end{equation*}
